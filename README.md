# Klondike Solitaire - CSC200 DSA Mid Project

Klondike Solitaire game in Python (text interface + Tkinter GUI).

## Data Structures Used
- Array/List: Deck of 52 cards (Fisher-Yates shuffle)
- Queue (FIFO): Stockpile (draw pile)
- Stack (LIFO): Foundation piles, waste pile, undo/redo history
- Linked List: Tableau columns
- Dictionary: Pile maps and card location map

## Features
Card moves, legal move validation, card flipping, draw 1 or draw 3,
win condition, undo/redo, hint system, timer and scoring.

## How to Run
- GUI: python solitaire_gui.py
- Text version: python solitaire.py
- Tests: python test_solitaire.py

## Files
- solitaire.py: game logic and data structures
- solitaire_gui.py: Tkinter graphical interface
- test_solitaire.py: unit tests
